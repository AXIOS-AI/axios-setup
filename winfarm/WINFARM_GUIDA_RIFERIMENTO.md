# WINFARM — Guida di Riferimento

## Descrizione
Winfarm è il gestionale per farmacie. Questo profilo contiene la configurazione WrenAI per l'interrogazione in linguaggio naturale dei dati Winfarm esportati.

## Tabelle principali
- ANAGR: Anagrafica pazienti
- ANAAC: Clienti
- ANAFORN: Fornitori
- PRODOTTI: Prodotti farmaceutici
- RICETTEX: Ricette SSN
- LG_TESTA: Scontrini/Testate
- MEDICI: Medici

## Database
- Sorgente: Firebird su localhost
- Target: DuckDB/SQLite per WrenAI
